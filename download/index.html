Need more help installing?
  1. Install BakkesMod first if you don’t already have it, then launch Rocket League with BakkesMod running.
  2. Click Download Now. Chrome and Edge often block the .dll as “unverified.” That’s normal — open your downloads page and choose Keep / Download unverified file.
  3. Press Win+R, paste %AppData%\bakkesmod\bakkesmod\plugins, and hit Enter.
  4. Copy RLTAS.dll into that folder.
  5. In Rocket League, press F2, then go to Plugins → RLTAS. If it isn’t listed, press F6 and type plugin load rltas.
  6. Free features work right away. Paid tiers are bought from inside the plugin, tied to your Epic or Steam ID.
