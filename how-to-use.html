FAQ

Common questions

What is a TAS tool?

A TAS (Tool Assisted Speedrun) tool is a piece of software that allows users to record and playback inputs in order to do things that are otherwise impossible. For example; with TAS you can lower game speed, record a series of inputs, and then restore game speed to see those same inputs replay in real time.

How do I install the plugin?

1. Download the plugin. (Chromium browsers may block the .dll file from downloading due to the file being "unverified". This is normal, simply open your downloads page and click "download unverified file".)

2. Copy the .dll file and paste it into your %AppData%\bakkesmod\bakkesmod\plugins directory. 

Does this plugin have a watermark to prevent people from faking freestyle clips? 

Yes. We are not interested in supporting anyone who wants to fake clips for views. The watermark included in this plugin is also not a simple text overlay. The plugin changes the colors of several effects (jump cloud, contact sparks, ball outline, etc). This color can be customized in the settings tab but the plugin will prevent you from choosing anything that is too close to the default colors that Rocket League uses.

Was AI used during development of this plugin?

Yes, generative AI was used throughout the creation of this plugin.

What should I do if I find a bug or glitch?

Please head to the discord and report it in the "bug-report" channel.

Is an internet connection required to use this plugin?

Yes. The plugin checks to see if your Epic/Steam ID is tied to an upgraded tier purchase.
